# Hesab Dəftərim — Personal Budget

![React Native](https://img.shields.io/badge/React%20Native-3b3a36?style=flat-square) ![Expo](https://img.shields.io/badge/Expo-3b3a36?style=flat-square) ![AsyncStorage](https://img.shields.io/badge/AsyncStorage-3b3a36?style=flat-square)


A pocket ledger for everyday money: what came in, what went out, and who owes whom.

## Screens
| Screen | What it shows |
|---|---|
| **Overview** | Total balance, debts due, monthly income vs. expense, breakdown by category, transaction list |
| **Debts** | Active debts sorted by due date with overdue warnings, partial or full repayment, paid history |
| **Add** | One form for income, expense or debt |

## Details
- **Offline-first** — all data stays on the phone
- Import / export of data files and sharing
- Local signed APK pipeline without EAS (own keystore, versioned builds)
